# Why there is no front end

A distribution desk follows records: what product was supplied, which document edition applies, who still needs it and which delivery has evidence. The CLI reads and updates those records. Branded HTML snapshots show the week without running a server.

This is useful for the operator who manages document versions and follow-ups. It is not a shop-floor emergency SDS reader or a public document portal. Mobile access, offline emergency access, QR scanning, live delivery connections, authenticated team screens and customer self-service need a scoped implementation. Keep the existing access and delivery systems until those paths are tested.

The database is the system of record. Claude Code, Codex, OpenCode or Cursor can read the same instructions and use the same CLI. Add a report through /new-view, or a field through /customise. No separate application is required for these internal review tasks.
